# Dashboard Pembangunan Wilayah Jawa Timur

Dashboard interaktif untuk analisis klasterisasi dan regresi indikator pembangunan 38 kabupaten/kota di Jawa Timur (Data 2025).

## Cara Menjalankan
1. Download repository ini, lalu ekstrak.
2. Pastikan Python sudah terpasang (versi 3.12 atau 3.13).
3. Klik dua kali file `run_dashboard.bat`.
4. Tunggu proses instalasi library selesai (hanya di percobaan pertama).
5. Browser akan otomatis membuka `http://localhost:8501`.

## Sumber Data
Open Data Jatim & BPS Provinsi Jawa Timur, 2025.

## Metode
K-Means Clustering & Regresi Linier Berganda (Python: scikit-learn, statsmodels).
